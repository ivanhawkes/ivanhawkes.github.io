{{/* Featured image for a page: "featured.webp" in the page's own resources. Alt text and the caption under the image come from the page's resource config: resources: - src: 'featured.webp' params: title: 'Lemon Bars' # caption under the image caption: 'A photograph of...' # alt text A page without that metadata falls back to the page title for the alt text, so alt is never empty. Callers pass a dict: page the page to render, required caption true to ask for the caption under the image, which page layouts do and card partials do not inherit true to fall back to the parent section's image, as the page hero does; omitted here for a card, which reads its own bundle only link a URL to wrap the image in, which a card gives and a page does not; nothing is wrapped when the page has no image of its own sizes the `sizes` hint for the layout box the image is drawn in, and `widths` the ladder of variants to offer it; a card gives both to name its grid, and a page omits both for the full-width hero Nothing is written at all when the lookup finds no image, so a card with no image of its own contributes no ``, no `` and no wrapper. */}} {{- $page := .page -}} {{- $showCaption := .caption -}} {{- $link := .link -}} {{- $sizes := .sizes -}} {{- $widths := .widths -}} {{- $inherit := true -}} {{- if isset . "inherit" -}} {{- $inherit = .inherit -}} {{- end -}} {{- with $page -}} {{- $image := partial "/images/featured.html" (dict "page" . "inherit" $inherit ) -}} {{- with $image -}} {{- $meta := .Params | default dict -}} {{- $ctx := dict "image" . "destination" .RelPermalink "title" (cond $showCaption $meta.title "") "alt" ($meta.caption | default $page.LinkTitle) "sizes" $sizes "widths" $widths -}} {{- with $link -}} {{- end -}} {{- partial "/images/image-variants.html" $ctx -}} {{- with $link -}} {{- end -}} {{- end -}} {{- end -}}
