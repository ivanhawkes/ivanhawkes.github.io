{{/* Featured image for a page: "featured.webp" in the page's own resources. The page's own bundle is the only place the image is looked for, and an ancestor section is never asked: a featured image is shown only when it is unique to the page. The parent lookup repeated one section photograph as the hero of every page in the section and as the image of every image-less card in a listing, at the widest variant of one large file, and let a page be illustrated by a photograph that does not depict it. Alt text and the caption under the image come from the page's resource config: resources: - src: 'featured.webp' params: title: 'Lemon Bars' # caption under the image caption: 'A photograph of...' # alt text A page without that metadata falls back to the page title for the alt text, so alt is never empty. Callers pass a dict: page the page to render, required caption true to ask for the caption under the image, which page layouts do and card partials do not link a URL to wrap the image in, which a card gives and a page does not; nothing is wrapped when the page has no image of its own sizes the `sizes` hint for the layout box the image is drawn in, and `widths` the ladder of variants to offer it; a card gives both to name its grid, and a hero leaves both to this partial hero true for the hero at the head of a page, which sets the hint, the ladder and the class of the box that hero is drawn in; a card omits it A page hero is drawn in the measure the prose is read in: `images.css` caps `featured-image`, the class a hero takes, at `--prose-measure`, the `65ch` the typography plugin gives `.prose`, so the picture is no wider than the paragraphs under it however far the window is stretched. The hint and the ladder name that box, so the browser is never offered a variant it cannot use: the measure is a little over 600 CSS pixels at the root size, less on a narrow window, and the ladder stops at 1280, which fills it at 2x density. The full-width hint used to ask for the 1600 and 1920 variants of a featured image, a 363 KB file drawn 600 pixels wide, and a hero never fetches them. Nothing is written at all when the page has no image of its own, so a page or card whose bundle carries no `featured.webp` contributes no ``, no `` and no wrapper. */}} {{- $page := .page -}} {{- $showCaption := .caption -}} {{- $link := .link -}} {{- $sizes := .sizes -}} {{- $widths := .widths -}} {{- $hero := .hero -}} {{- $heroSizes := "(min-width: 1024px) 65ch, calc(100vw - 60px)" -}} {{- $heroWidths := slice "320" "640" "960" "1280" -}} {{- $class := "" -}} {{- if $hero -}} {{- $sizes = $heroSizes -}} {{- $widths = $heroWidths -}} {{- $class = "featured-image" -}} {{- end -}} {{- with $page -}} {{- with .Resources.GetMatch "featured.webp" -}} {{- $meta := .Params | default dict -}} {{- $ctx := dict "image" . "destination" .RelPermalink "title" (cond $showCaption $meta.title "") "alt" ($meta.caption | default $page.LinkTitle) "sizes" $sizes "widths" $widths "class" $class -}} {{- with $link -}} {{- end -}} {{- partial "/images/image-variants.html" $ctx -}} {{- with $link -}} {{- end -}} {{- end -}} {{- end -}}
