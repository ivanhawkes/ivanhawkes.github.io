{{/* Featured image for a page: "featured.webp" in the page's own resources. The page's own bundle is the only place the image is looked for, and an ancestor section is never asked: a featured image is shown only when it is unique to the page. The parent lookup repeated one section photograph as the hero of every page in the section and as the image of every image-less card in a listing, at the widest variant of one large file, and let a page be illustrated by a photograph that does not depict it. Alt text and the caption under the image come from the page's resource config: resources: - src: 'featured.webp' params: title: 'Lemon Bars' # caption under the image caption: 'A photograph of...' # alt text A page without that metadata falls back to the page title for the alt text, so alt is never empty. Callers pass a dict: page the page to render, required caption true to ask for the caption under the image, which page layouts do and card partials do not link a URL to wrap the image in, which a card gives and a page does not; nothing is wrapped when the page has no image of its own sizes the `sizes` hint for the layout box the image is drawn in, and `widths` the ladder of variants to offer it; a card gives both, as the `card` box of `images/boxes.html`, and a hero leaves both to this partial hero true for the hero at the head of a page, which takes the `prose` box of `images/boxes.html` and the class that box is capped at; a card omits it A page hero is drawn in the measure the prose is read in: `images.css` caps `featured-image`, the class a hero takes, at `--prose-measure`, the `65ch` the typography plugin gives `.prose`, and centres the column, so the picture is no wider than the paragraphs under it, and sits with them in the middle of the panel, however far the window is stretched. Its hint and ladder are the `prose` box, which names that column and stops at 1280, the width that fills it at 2x density. The full-width hint this path used to send asked the browser for the 1600 and 1920 variants of a featured image: 99 KB drawn in a box about 600 pixels wide. Nothing is written at all when the page has no image of its own, so a page or card whose bundle carries no `featured.webp` contributes no ``, no `` and no wrapper. */}} {{- $page := .page -}} {{- $showCaption := .caption -}} {{- $link := .link -}} {{- $sizes := .sizes -}} {{- $widths := .widths -}} {{- $hero := .hero -}} {{- $class := "" -}} {{- if $hero -}} {{- $box := (partial "/images/boxes.html").prose -}} {{- $sizes = $box.sizes -}} {{- $widths = $box.widths -}} {{- $class = "featured-image" -}} {{- end -}} {{- with $page -}} {{- with .Resources.GetMatch "featured.webp" -}} {{- $meta := .Params | default dict -}} {{- $ctx := dict "image" . "destination" .RelPermalink "title" (cond $showCaption $meta.title "") "alt" ($meta.caption | default $page.LinkTitle) "sizes" $sizes "widths" $widths "class" $class -}} {{- with $link -}} {{- end -}} {{- partial "/images/image-variants.html" $ctx -}} {{- with $link -}} {{- end -}} {{- end -}} {{- end -}}
