{{/* The featured image of a page, as a page resource: "featured.webp" in the page's own resources. Returns nil when the page has none, so a caller can tell a card with no image from a card with one and render nothing for the image of the first. Callers pass a dict: page the page to look for an image on inherit true to fall back to the parent section's image. A page asks for this: a post whose bundle carries no `featured.webp` is shown with its section's photograph as its hero, which is the intent. A card never does. In a listing the fallback repeats one section image across every image-less card, and the same large file at its widest variant, so a card reads its own resources only. */}} {{- $page := .page -}} {{- $inherit := false -}} {{- if isset . "inherit" -}} {{- $inherit = .inherit -}} {{- end -}} {{- $prefix := "featured.webp" -}} {{- $image := false -}} {{- with $page -}} {{- with .Resources -}} {{- $image = .GetMatch $prefix -}} {{- end -}} {{- if and (not $image) $inherit -}} {{- with .Parent -}} {{- with .Resources -}} {{- $image = .GetMatch $prefix -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- return $image -}}
