{{/* The placeholder rules of one page, in a `style` block in its head. An image is drawn by `images/image-variants.html`, the `img` shortcode or the Markdown image render hook, and each of them records the image, with the placeholder format it used, through `images/placeholder-register.html`. This partial writes one rule per record, and deletes them: the selector is `.imgB-` plus the record key, the same string the class on the image box is built from, so a selector and the class that asks for it always agree, and an image drawn twice on a page is given one rule. An image drawn by a card is an image of another page: a walk over the current page's resources never reaches it, so a listing would carry no placeholder for any card, and would carry rules for the images of its own bundle that no card uses. `meta/head.html` therefore defers this partial to the second render pass, by which time the page has drawn everything it draws: the rules cover the images of the pages it lists, and a page that draws no image writes no block at all. The page to read is the one the head passes, because a page in the second pass has lost the pagination that named its pager. GIP is a gradient of the dominant colours of the image; LQIP is a 20 pixel wide copy of it, base64 encoded into the rule. Both fill a box at the source's aspect ratio, which is why an image box reserves its space before the image arrives. key the Scratch key of the page render, from images/placeholder-key.html */}} {{- $key := .key -}} {{- $records := page.Scratch.Get $key | default slice -}} {{- $seen := slice }} {{- $void := page.Scratch.Delete $key }} {{- with $records }} {{- end -}}
