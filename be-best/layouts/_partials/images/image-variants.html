{{/* An image as a `picture`: webp and jpeg srcsets over a ladder of widths, plus a small jpeg `img` fallback. Callers pass a dict: image the page resource to render, required title a caption under the image; omit for no caption alt the alt text sizes the `sizes` hint naming the breakpoints the layout box moves across widths the width ladder to emit class a class on the box around the image, for a caller whose layout sizes that box; omitted for a caller that leaves it alone `sizes` and `widths` travel together, and a caller takes both from one box of `images/boxes.html`, which names every box the theme draws an image in: the pair narrows the ladder to the variants the layout box can actually select, so the browser is never offered a file it cannot use. Each width is skipped when the source is narrower. A caller that passes one without the other asks for a box that partial does not name, and the build fails. The box is classed `imgB--LQIP`, the placeholder that fills it while the picture loads, and the image is registered for that rule. The hash is the md5 of the image's `RelPermalink`, its own address: featured images are all named `featured.webp`, so a hash of the name alone gives every image on a page the same placeholder, the last rule written winning. `images/image-process.html` hashes the same string, and `images/placeholder-register.html` is what hands the image to it. */}} {{- $image := .image -}} {{- $alt := .alt -}} {{- $class := .class -}} {{- $sizes := .sizes -}} {{- $widths := .widths -}} {{- if not (and $sizes $widths) -}} {{- errorf "image-variants.html: an image needs a box, `sizes` and `widths` from images/boxes.html" -}} {{- end -}} {{- $sizeList := $widths -}} {{- $blurFormat := "LQIP" -}} {{- $hint := "photo" -}} {{- $filter := "box" -}} {{- $imgClass := "w-full rounded-md h-auto shadow animate-fade" -}} {{ with $image }} {{- $imgRsc := . -}} {{- $imageMD5 := md5 $imgRsc.RelPermalink -}} {{- $classes := slice "relative" "bigImgDiv" -}} {{- with $class -}} {{- $classes = $classes | append . -}} {{- end -}} {{- $classes = $classes | append (print "imgB-" $imageMD5 "-" $blurFormat) -}} {{- $divClass := delimit $classes " " -}} {{- partial "/images/placeholder-register.html" (dict "image" $imgRsc "format" $blurFormat "page" page ) -}} {{- $actualImg := $imgRsc.Process (print "resize 640x jpg " $filter) -}}
