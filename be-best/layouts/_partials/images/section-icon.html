{{/* The icon of the section a page belongs to: the SVG its menu entry carries in `params.icon`, taken from the page itself when it has a menu entry, else from its nearest ancestor that has one. A card with no featured image of its own shows it in place of a photograph, so an image-less listing still reads as designed. The icons stay defined once, in the menu front matter. . the page Returns the SVG markup, or "" when no ancestor has an icon. */}} {{- $icons := partialCached "/images/section-icon-map.html" "map" -}} {{- $found := "" -}} {{- range (slice .) | append .Ancestors -}} {{- if not $found -}} {{- with index $icons .Path -}} {{- $found = . -}} {{- end -}} {{- end -}} {{- end -}} {{- return $found -}}
