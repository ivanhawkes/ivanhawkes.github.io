{{/* Taxonomy: the tags and categories a page is filed under, in one line at its foot, under the prose that names them. The old line set the kinds apart with `⏺`, which is U+23FA in the Enclosed Alphanumeric Supplement: where emoji presentation is the default a phone draws it as a black circle on a coloured plate, so the separator arrived as a square of colour unrelated to the theme. The kinds now meet at a dot the CSS draws, in the colour of the line it sits in, sized in `em` so it scales with the type it separates; `navigation.css` owns the line, the label, the link and the dot, and this partial states the terms and links them to the term pages. A kind with no terms renders nothing, and a page filed under nothing renders no line at all, so a page is never given an empty rule where its taxonomies should have been. */}} {{- $taxonomies := .Params.taxonomies -}} {{- $categories := .Params.categories -}} {{- if and (not .Params.omitTaxonomy) (or $taxonomies $categories) -}}

  • Tags {{- range . -}} {{- $permalink := (printf "%s%s/" ($.Site.GetPage "taxonomy" "tags").RelPermalink (urlize .)) -}} {{- . -}} {{- end }}
    • {{- end }} {{- with $categories }}
  • Categories {{- range . -}} {{- $permalink := (printf "%s%s/" ($.Site.GetPage "taxonomy" "categories").RelPermalink (urlize .)) -}} {{- . -}} {{- end }}
