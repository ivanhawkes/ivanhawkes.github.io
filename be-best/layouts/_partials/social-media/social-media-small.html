{{/* The author's accounts, as icon-only marks: one link per account, in the order below. Params: accounts - the account map; defaults to the `social:` map of `config/_default/params.yaml`, whose keys name the accounts: github, facebook, youtube, twitter. A key that is not set writes no mark. class - the class of the wrapper, which is the hook the calling context styles by. The byline passes `byline-links`, whose rules are in `be-best/assets/css/byline.css` and which `print.css` hides on paper. owner - the name the labels read; defaults to `site.Params.copyright.owner`. The mark carries no words, so every link names itself in `aria-label`: a screen reader reads "GitHub profile of Ivan Hawkes", never the brand glyph, and the svg is hidden from the accessibility tree. Each link leaves the site, so `rel="noopener"` keeps the opened page from reaching back at this one. Size and colour are CSS, never attributes: the paths are monochrome and take `currentColor`, so the calling context recolours and resizes the marks with its own rules, in both schemes, on paper, and under forced colours. Where a mark shows the page through itself - the YouTube play, the Facebook letter - that section is a cut-out, classed for the CSS to paint with the ground, never a colour baked into the path. */}} {{- $accounts := default site.Params.social .accounts -}} {{- $owner := default site.Params.copyright.owner .owner -}} {{- $class := default "social-links" .class -}} {{ with $accounts.github }} {{ end }} {{ with $accounts.facebook }} {{ end }} {{ with $accounts.youtube }} {{ end }} {{ with $accounts.twitter }} {{ end }}
