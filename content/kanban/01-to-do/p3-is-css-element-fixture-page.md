## Css Element Fixture Page

The `dashboard` section that held `raw/all-html-elements.html`, a hand-written
run of every element for eyeballing the stylesheet, is gone: no section, no
layout, no generated output. `p2-is-agent-docs-claim-a-dashboard-section`
brought the documents in line with the tree instead of reviving the section, and
the fixture's value went with it. Theme work is done blind now, and the deleted
Lorem Ipsum scaffold in `be-best/layouts/baseof.html` (see
`p3-is-baseof-lorem-ipsum-block`) was a shadow of the same page.

`be-best/layouts/raw.html` is `.Content` and nothing else, so a page that sets
`layout: raw` renders bare, with no site chrome around the markup.

## Goals

- [ ] Add a section under `content/` whose pages set `layout: raw`, and document
      it in `AGENTS.md` beside the other content sections.
- [ ] Fill one page with the elements the stylesheet styles: headings,
      paragraphs, lists, tables, code, blockquote, figures with images, buttons,
      links, and the Kanban and card classes the theme ships.
- [ ] Keep the page out of navigation: no `menus` entry.
- [ ] Keep both validators green without adding a directory skip to
      `scripts/validate-headings.mjs`: the page carries the
      `<!-- h1-check: ignore -->` comment the script honours.

## Acceptance Criteria

- [ ] The fixture is generated by `pnpm run build:hugo` at the path `AGENTS.md`
      names.
- [ ] The rendered page has no `nav`, `header` or `footer` landmark.
- [ ] `pnpm run test:html` and `pnpm run test:headings` pass with the page
      present, and `scripts/validate-headings.mjs` skips no directory.
- [ ] `pnpm run test` passes.
