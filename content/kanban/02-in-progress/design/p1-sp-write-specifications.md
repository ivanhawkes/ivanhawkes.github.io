## Write Specifications

- [ ] gather the requirements from the stakeholders
- [ ] analyse the requirements
- [ ] write a specification that clearly lays out all the agreed upon
      requirements for the client
- [ ] write a functional specification based on the requirements specification
- [ ] write a technical specification based on the requirements specification
- [ ] write a test specification based on the requirements, functional and
      technical specifications

## Acceptance Criteria

- [ ] a completed requirements specification
- [ ] a completed functional specification
- [ ] a completed technical specification
- [ ] a completed test specification
