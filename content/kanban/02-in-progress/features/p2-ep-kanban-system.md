Create a Kanban card system that is fully integrated into the design and
development process. It should be able to be maintained using just the code
editor.

The system should provide the means for tracking ideas, requests, features and
all other common forms of documentation.

<!--more-->

## Create Kanban System

- [ ] Epics should get their completion and actual times from the related
      features and requests
- [ ] Cards for tracking each part of the development cycle
- [ ] Charts for tracking progress
    - [ ] Burn down
    - [ ] Kanban board
