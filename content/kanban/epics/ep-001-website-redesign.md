After thirteen long years, the time has come to completely redesign my personal
website. While I'm perfectly happy with HUGO, the look and feel of the site is
tired and dated.

It lacks responsive design affordments. There is no scaling of images for
mobile, or slow internet connections. The SEO features are out of date.

<!--more-->

- Epics should get their completion and actual times from the related features
  and requests
- Remove the old Bootstrap CSS
- Choose a modern development environment
- Update the SEO / meta data for the site
- Refresh the images for design elements as well as basic content
- Change the structure to use branch bundles, bringing all the content for a
  single post into one folder
- Add modern elements
  - Light / dark mode
  - Hamburger menu
  - Code copy button
  - Search engine integration
- Consider putting some usage monitoring on the site to see which sections are
  being used and how much time I've wasted for so few page impressions
